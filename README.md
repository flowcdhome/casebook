# Casebook

Рабочее место для OSINT-расследований: дела, зацепки, проверки по нику, почте и домену, холст со стрелками и экспорт отчёта. Вместо таблиц и текстовых документов.

Всё хранится у вас на компьютере. Закрыли программу, выключили ПК, завтра открыли, и всё на месте.

> Используйте только открытые данные и только законным образом. Программа лишь помогает организовать работу.

## Возможности

- **Дела и зацепки.** Зацепка это ник, почта, телефон, домен, ip, ссылка, имя или заметка. Тип определяется сам.
- **Проверка прямо внутри.** Для ника запускаются Sherlock и Maigret, для почты holehe, для домена whois. Найденное складывается под зацепку, лишнее удаляется, нужное одним нажатием становится новой зацепкой.
- **Быстрые ссылки и Google-dork шаблоны** для каждой зацепки. Нашли ник через dork, нажали «в зацепки» и сразу проверили.
- **Сервисы в отдельном окне.** Любой сайт (osintsearch, osintlist и т. п.) открывается внутри программы, вход на сайте сохраняется. Кнопки «Забрать ссылки» и «Забрать выделенное» переносят результат под зацепку.
- **Холст.** Блоки и стрелки, картинки из буфера (Ctrl+V), шаблон «Информация о человеке», выделение рамкой, группы, выравнивание, отмена и повтор, подписи на стрелках.
- **Контекстные меню (ПКМ)** на блоках, стрелках и пустом месте.
- **Работа с клавиатуры.** Палитра команд (Ctrl+K), перемещение блоков и переход между ними стрелками, дочерние блоки по Tab. Клавиши привязаны к физическим кнопкам и работают и в русской раскладке.
- **Настройка двумя способами.** Через окно «Настройки» и через текстовый файл `config.json`. Это один и тот же файл, изменения подхватываются без перезапуска.
- **Экспорт дела в Markdown** (зацепки, найденное, блоки и связи холста).
- Обучение при первом запуске (повтор: F1).

## Установка

Нужны только `curl` или `wget` и один из `bsdtar`, `unzip`, `python3`. Node.js не нужен: установщик скачивает готовый Electron и кладёт его в папку проекта.

```bash
git clone https://github.com/flowcdhome/casebook.git
cd casebook
sh install.sh
casebook
```

Установщик создаёт команду `casebook` в `~/.local/bin` и ярлык в меню приложений. Если у вас уже стоит Electron (пакет `electron` или другая программа на нём), он будет использован. Свой путь можно задать так: `ELECTRON_BIN=/путь/к/electron sh install.sh`.

### Arch Linux

```bash
sudo pacman -S --needed git curl          # если чего-то нет
git clone https://github.com/flowcdhome/casebook.git && cd casebook && sh install.sh
```

Можно использовать системный Electron: `sudo pacman -S electron`, затем `sh install.sh`. Дополнительные программы проверки:

```bash
sudo pacman -S --needed python-pipx
pipx install sherlock-project maigret holehe
```

### Debian / Ubuntu

Проверено на Arch. Для Debian и Gentoo инструкции составлены по документации дистрибутивов: если что-то не сработает, откройте issue с выводом ошибки.

```bash
sudo apt install git curl unzip
git clone https://github.com/flowcdhome/casebook.git && cd casebook && sh install.sh
```

Дополнительные программы проверки:

```bash
sudo apt install pipx whois
pipx install sherlock-project maigret holehe
pipx ensurepath
```

Если установщик сообщит о недостающих библиотеках (на минимальных установках Debian это обычное дело), он сам напишет нужную команду `apt install`. Для справки, обычно это: `libgtk-3-0 libnss3 libxss1 libgbm1 libxtst6 libnotify4 libxkbcommon0 libatspi2.0-0 libdrm2` и `libasound2` (на Debian 13 и Ubuntu 24.04: `libasound2t64`).

На **Ubuntu 24.04 и новее** AppArmor ограничивает песочницу Chromium. Установщик замечает это и запускает программу с `--no-sandbox`. Если окно не открывается и в терминале видно сообщение про SUID sandbox, запустите вручную `casebook --no-sandbox`.

### Gentoo

```bash
sudo emerge --ask dev-vcs/git net-misc/curl app-arch/unzip
git clone https://github.com/flowcdhome/casebook.git && cd casebook && sh install.sh
```

Electron из архива требует обычных библиотек рабочего стола (GTK 3, NSS, ALSA, libXScrnSaver, libnotify); при обычной графической установке они уже есть. Дополнительные программы проверки (если пакета `pipx` нет в вашем дереве, поставьте его через `python3 -m venv`):

```bash
sudo emerge --ask dev-python/pipx net-misc/whois
pipx install sherlock-project maigret holehe
```

### Если что-то не работает

| Симптом | Что делать |
|---|---|
| `casebook: команда не найдена` | Добавьте `export PATH="$PATH:$HOME/.local/bin"` в `~/.profile` и перезайдите. |
| Проверка пишет «не найден» | Программа не установлена или её нет в `PATH`. Установите (см. выше) или укажите полный путь в `config.json` (`runners`). |
| Окно не открывается, ошибка про sandbox | `casebook --no-sandbox`. |
| Дела не видны после обновления | Они лежат в `~/.config/casebook/cases.json`. Резервная копия: `cases.json.bak`. |

## Первые шаги

1. Создайте дело (Ctrl+N) и добавьте первую зацепку (Ctrl+L): то, что у вас есть.
2. Нажмите проверку (Sherlock, Maigret…) или откройте быстрые ссылки и dork.
3. Нужное из найденного отправляйте «в зацепки». Новые зацепки проверяйте так же.
4. Связи рисуйте на холсте: кнопка «На холст» у зацепки или шаблон «человек».
5. В конце: «Экспорт .md».

## Сервисы с входом (osintsearch, osintlist и др.)

В `config.json` в разделе `services` перечислены сайты. У зацепки появляются кнопки с их названиями. Нажатие открывает сайт в отдельном окне с постоянной сессией: войдите один раз, дальше вход сохраняется. Если в адресе есть `{v}`, туда подставляется значение зацепки.

Когда результат на странице, нажмите **«Забрать ссылки»** (все внешние ссылки страницы попадут под зацепку) или выделите нужный текст и нажмите **«Забрать выделенное»**. Капчи и формы остаются на самом сайте, поэтому проблем с ними нет.

Если сайт не пускает во встроенное окно (например, капча не грузится), нажмите **«В браузере»** в панели окна, сделайте поиск там, выделите результат, скопируйте и нажмите у зацепки **«Вставить найденное из буфера»**.

### Проверка Cloudflare («докажите, что вы человек»)

Многие сервисы стоят за Cloudflare. В окне сервиса проверка проходится так же, как в обычном браузере: вы нажимаете галочку сами. Casebook не обходит и не решает её автоматически. Если проверка не загружается («CAPTCHA could not load»):

1. Запустите `casebook` из терминала, откройте сервис и посмотрите строки `[casebook] [сервис] …`: они покажут, какие запросы не прошли (например, домены `challenges.cloudflare.com`). Если они заблокированы DNS-фильтром, VPN или блокировщиком на уровне сети, их нужно разрешить.
2. Нажмите **«В браузере»** в панели окна сервиса: страница откроется в вашем обычном браузере, где проверка проходится как обычно. Результат выделите и скопируйте, затем в Casebook нажмите **«Вставить найденное из буфера»** под зацепкой.
3. Многие сервисы дают больше проверок и пропускают без капчи тех, кто вошёл в бесплатный аккаунт: зарегистрируйтесь на сайте обычным способом (почта и пароль) и входите в окне сервиса.

Честные ограничения:
- `osintsearch.org` работает с адресом вида `https://osintsearch.org/?q={v}` (проверено по скриншоту: поиск по нику без регистрации, 5 бесплатных проверок в день). Адрес `osintlist.cc` **не проверен**: уточните его и поправьте сами.
- Google может не пустить на вход из встроенного окна («браузер небезопасен»). Если так, используйте сайт в обычном браузере и переносите результат через буфер.
- Автоматического разбора содержимого конкретных сайтов нет: он зависел бы от их вёрстки и ломался бы при каждом изменении.

## Горячие клавиши

Все клавиши меняются в «Настройках» или в `config.json` (`binds` и `board`). Ниже значения по умолчанию.

| Общие | Клавиша | Холст | Клавиша |
|---|---|---|---|
| Палитра команд | Ctrl+K | Новый блок | N |
| Новое дело | Ctrl+N | Дочерний блок со стрелкой | Tab |
| Новая зацепка | Ctrl+L | Править текст | Enter, F2 |
| Экспорт .md | Ctrl+E | Выделить всё | Ctrl+A |
| Обучение | F1 | Снять выделение / отмена | Esc |
| Настройки | Ctrl+, | Сдвиг блоков | стрелки (Shift: крупно) |
| Вкладки | Alt+1 / 2 / 3 | Перейти к соседнему блоку | Alt+стрелки |
| | | Сдвиг холста | Ctrl+стрелки |
| | | Соединить стрелкой | L (затем Alt+стрелки, Enter) |
| | | Копировать, вырезать, дублировать | Ctrl+C, Ctrl+X, Ctrl+D |
| | | Отменить, повторить | Ctrl+Z, Ctrl+Shift+Z |
| | | Цвет | K |
| | | Сделать зацепкой | Shift+L |
| | | Вписать в экран, масштаб | F, = и − |
| | | Меню с клавиатуры | Shift+F10 |

Мышь на холсте: ПКМ открывает меню; рамка по пустому месту выделяет; точка ● у блока тянет стрелку (отпустите в пустом месте, чтобы создать новый блок); пробел или средняя кнопка двигают холст; колесо масштабирует; двойной клик по пустому месту создаёт блок, по стрелке подписывает её; Ctrl+V вставляет картинку или текст.

## Настройка (`config.json`)

Файл: `~/.config/casebook/config.json` (создаётся при первом запуске со всеми значениями). Можно удалять любые ключи: недостающие берутся из значений по умолчанию.

```json
{
  "accent": "#d9a441",
  "boardStep": 10,
  "boardBigStep": 60,
  "binds":  { "palette": "Ctrl+K" },
  "board":  { "newBlock": "N", "delete": ["Delete", "Backspace"] },
  "runners": {
    "sherlock": { "cmd": "sherlock", "args": ["{v}", "--print-found"], "types": ["username"], "timeout": 300 }
  },
  "services": [
    { "name": "Мой сервис", "url": "https://example.org/search?q={v}", "types": ["username", "email"] }
  ]
}
```

- `binds`, `board`: клавиши (строка или список). Формат: `Ctrl+Shift+Z`, `Alt+Left`, `F2`.
- `runners`: любые программы командной строки. `{v}` заменяется значением зацепки. Строки вида `[+] Сайт: https://…` в выводе автоматически попадают в «Найденное».
- `types`: для каких типов зацепок показывать кнопку (`username`, `email`, `phone`, `domain`, `ip`, `url`, `name`, `note`).

## Данные

- `~/.config/casebook/cases.json`: дела (резервная копия `cases.json.bak` обновляется раз в минуту при изменениях).
- `~/.config/casebook/config.json`: настройки.
- Чтобы перенести на другой компьютер, скопируйте оба файла.

## Разработка и проверка

```bash
npm install     # только для разработки
npm test        # автотесты: холст, приложение, главный процесс
npm start
```

Структура: `main.js` (хранение, запуск программ, окно сервиса), `renderer/app.js` (дела, зацепки, настройки), `renderer/board.js` (холст), `renderer/lib.js` (клавиши, меню, палитра), `test/` (тесты на имитации DOM).

### Известные ограничения (план исправлений)

- Холст не попадает в экспорт как картинка (только текст блоков и связей).
- Нет выбора формы блоков и нескольких стрелок разного типа между одной парой.
- Окно сервиса не проверялось на реальных сайтах; Google-вход может блокироваться.
- Автотесты используют имитацию DOM: поведение в реальном Electron проверяйте вручную.

## Что откуда взято

- **Electron** (MIT): оболочка приложения, скачивается установщиком с GitHub-релизов проекта electron/electron.
- **Sherlock**, **Maigret**, **holehe**, **whois**: сторонние программы, в проект не входят. Casebook лишь запускает их у вас на компьютере.
- **Быстрые ссылки** это адреса обычных поисковиков и открытых сервисов (Google, Bing, Yandex, GitHub, crt.sh, Wayback Machine, urlscan, Shodan и др.). Ничего с них автоматически не скачивается.
- Шаблон холста повторяет схему «информация о человеке» (документы, биография, данные в интернете, интересы, связи).
- Остальной код написан в этом проекте.
